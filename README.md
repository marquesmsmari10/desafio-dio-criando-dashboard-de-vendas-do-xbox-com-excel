# 🎮 Dashboard de Vendas: Xbox Analytics 📈

*Hello there! Welcome to my GitHub!* Meu nome é Mariana, sou professora de inglês de dia e aventureira no mundo dos dados à noite! 👩‍🏫💻✨ 

Este repositório contém a entrega do meu terceiro desafio prático pela **DIO (Digital Innovation One)**. Desta vez, unimos o universo *gamer* com *Data Analytics* para construir um Dashboard de Vendas do Xbox! 

Se você acha que Excel é só uma tabela chata com números em preto e branco, prepare-se para ver um verdadeiro *Level Up*! 🍄🌟

## 🎯 Objetivo do Projeto

O principal objetivo deste projeto foi transformar um conjunto de dados brutos e difíceis de ler (nossa `base.xlsx`) em um Dashboard claro, dinâmico e focado em tomada de decisões, chegando ao resultado esperado no arquivo de referência `dashboard_xbox_finalizado.xlsx`. 

Nós focamos em:
* Organização lógica das informações.
* Criação de KPIs (Key Performance Indicators) diretos e retos.
* Identidade visual imersiva (afinal, estamos falando de Xbox, então o verde e preto precisam dominar! 💚🖤).

## 🛠️ Tecnologias e Técnicas Aplicadas

Para chegar ao *Boss* final deste projeto, utilizei as seguintes habilidades:

1. **ETL Básico:** Extração, transformação e limpeza dos dados da base inicial.
2. **Tabelas Dinâmicas (Pivot Tables):** O coração do Dashboard! Usei para agregar as vendas por **Modelo de Console** e por **Região**.
3. **Data Visualization (Gráficos):**
   * 🍩 *Gráfico de Rosca:* Para mostrar a proporção de vendas entre o Xbox Series X, Series S e a geração anterior.
   * 📊 *Gráfico de Barras Horizontais:* Para ranquear as regiões mais lucrativas (Norte América, Europa, etc).
4. **UX/UI Design no Excel:** Remoção de linhas de grade, aplicação de paleta de cores corporativa da marca, uso de ícones e formatação condicional.

## 🚀 Como reproduzir este Dashboard

Se você quer clonar essa experiência e criar o seu próprio painel de vendas no Google Sheets ou Excel:

1. Baixe o arquivo disponível neste repositório.
2. Importe-o para o Excel ou Google Sheets (ele contém a base de dados e a estrutura de agregações).
3. Selecione as tabelas de resumo e insira os gráficos correspondentes.
4. Oculte a aba de "Base de Dados" para que o usuário final veja apenas a tela do Dashboard (uma ótima prática de *clean design*!).
